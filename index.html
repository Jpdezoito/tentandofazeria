🤖 Sistema de IA Conversacional com RNA

Um sistema avançado de inteligência artificial para conversação natural

📋 Sobre o Projeto

Este é um sistema completo de IA conversacional desenvolvido com PyTorch, utilizando técnicas modernas de aprendizado de máquina como LoRA (Low-Rank Adaptation) para fine-tuning eficiente de modelos de linguagem.

✨ Características Principais

🧠 Modelo de Linguagem GPT-2: Baseado no GPT-2 com fine-tuning personalizado para conversação em português.
🔄 Treinamento Flexível: Suporte a múltiplos otimizadores (Adam, AdamW, SGD, RMSprop, etc.) e schedulers de learning rate.
💬 Interface Gráfica: GUI moderna desenvolvida com CustomTkinter para interação fácil.
🔗 Integração com Ollama: Suporte a modelos locais via Ollama com fallback automático.
📚 Sistema RAG: Retrieval-Augmented Generation para respostas baseadas em conhecimento personalizado.
🎯 Avaliação Automática: Sistema de avaliação de coerência e qualidade das respostas.

🚀 Como Usar

Opção 1: Docker (Recomendado)

Para a experiência mais fácil:

docker-compose up --build

Isso inicia tanto a IA quanto o Ollama automaticamente!

Opção 2: Instalação Manual

  1. Clone o repositório: git clone https://github.com/Jpdezoito/tentandofazeria.git
  2. Instale as dependências: pip install -r requirements.txt
  3. Execute a interface principal: python ia_principal/main.py
🎯 Experimentar Demo Interativa

📁 Estrutura do Projeto

  • src/core/: Componentes principais (RNA, avaliador, UI components)
  • src/ui/: Interfaces gráficas (GUI principal)
  • src/backend/: Módulos backend especializados
  • src/tools/: Ferramentas e utilitários
  • src/config/: Configurações centralizadas
  • data/: Dados organizados (raw, training, models)
  • docs/: Documentação do projeto

🔧 Tecnologias Utilizadas

  • PyTorch: Framework principal para deep learning
  • Transformers: Biblioteca Hugging Face para modelos de linguagem
  • PEFT: Parameter-Efficient Fine-Tuning (LoRA)
  • CustomTkinter: Interface gráfica moderna
  • Ollama: Integração com modelos locais
  • Scikit-learn: Avaliação e métricas
